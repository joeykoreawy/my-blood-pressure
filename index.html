설치 · 정보

MyPressure V1.0
Safari에서 공유 → 홈 화면에 추가 → 웹 앱으로 열기를 선택하면 일반 앱처럼 실행됩니다. 앱 화면과 로컬 기록은 오프라인에서도 사용할 수 있고, 인터넷이 연결되면 로그인 계정과 동기화합니다.
GitHub Pages에는 앱 코드만 올라가며 혈압 기록은 GitHub에 저장되지 않습니다. 서버 동기화 기록은 사용자의 Supabase 프로젝트에 저장됩니다.
